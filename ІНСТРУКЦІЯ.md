# Сайт «Шо по стейкам?» — как менять

Сайт — обычные файлы, без сборки. Открыть: двойной клик по `index.html`
(или залить всю папку на хостинг / GitHub Pages как есть).

## Где что лежит
| Что поменять | Файл |
|---|---|
| Цены, товары, описания, бейджи, вес порции | `js/products.js` |
| Телефон, Instagram, Telegram, минимальный заказ, цена доставки, кодовое слово | `js/config.js` |
| Фото товаров | папка `images/` + поле `photo` в `js/products.js` (см. ниже) |
| Фото первого экрана, баннер, фон бургеров | `images/hero.webp`, `images/banner.webp`, `images/burgers-bg.webp` |
| Тексты разделов, отзывы | `index.html` |
| Цвета бренда | `css/styles.css`, самый верх (`:root`) |

## Цены
В `js/products.js` у стейков два числа: `perKg` (цена за кг) и `weight` (вес порции, г).
Цена порции на карточке считается сама: `perKg × weight`, округление до 5 ₴.
У бургерных котлет — фиксированная `price` и подпись `pack`.

## Добавить / скрыть товар
Скопируйте строку товара, поменяйте `id` (латиницей, уникальный) и поля.
Скрыть без удаления — добавить `hidden: true`.
Бейдж: `'Хіт'`, `'Новинка'`, `'Витримка 21 день'` или `''`.

## Фото
Все фото сайта — в папке `images/` (оригиналы не трогаются).
Добавить фото товару (нужен Python с Pillow — он уже стоит на этом Mac):
```
python3 tools/photo.py "путь/к/фото.jpg" bavette
```
Скрипт сделает `images/bavette.webp` (1200px), `-600` версию и круглую миниатюру.
Потом в `js/products.js` у товара: `photo: 'images/bavette.webp'`.
Пока `photo: ''` — показывается тёмная заглушка «Фото незабаром».

Большая карточка на 2 колонки в «Класичних» — `featured: true` у товара.
Фото первого экрана — `images/hero.webp`, баннер — `images/banner.webp`,
фон бургеров — `images/burgers-bg.webp` (замените файл с тем же именем).

## Телефон
`js/config.js`: `phone` — как показывать, `phoneHref` — для звонка в формате `+380671234567`.

## Отправка заказов в Telegram
Сейчас заказ только показывается клиенту («Дякуємо!») и пишется в консоль браузера.
Чтобы заказы приходили в бот: сделать Cloudflare Worker (как на horeca-сайте), который
принимает POST `{ order, text }` и пересылает `text` в Telegram, и вписать его адрес в
`orderEndpoint` в `js/config.js`. Токен бота на сайт не класть.
